# 比特币技术入门 · 从零开始，一层一层挖下去

一本从技术角度讲清比特币的电子书，以及配套的可运行代码。

不假设读者懂密码学、经济学或编程。从"两个人怎么记账"这种最朴素的问题开始，
每章只增加一个新概念，直到读者能生成密钥、签出交易、解析原始字节、写出一个能跑的区块链。

## 快速开始

**读书**（不需要安装任何东西）：

```bash
open bitcoin-from-scratch.html      # macOS
# 或者直接用浏览器打开这个文件
```

单文件、无外部依赖，双击即可。带侧边目录导航、代码语法高亮、19 张图表。

**跑代码**：

```bash
cd code
python3 run_all.py        # 一键运行全部 14 个示例
```

或单独运行某一个：

```bash
cd code
python3 ch03_ecdsa.py     # 例如：看看复用随机数怎么泄露私钥
```

## 环境要求

- Python **3.8+**（只用标准库，`hashlib` / `hmac` / `secrets`）
- 不需要 `pip install` 任何东西
- `code/english.txt` 是 BIP39 官方 2048 词表，`ch15_bip39.py` 需要它

## 关于代码

`btclib.py` 里每一个函数都标注了它在书中对应的章节。几个关键实现都用了**官方测试向量**验证：

- `secp256k1`：私钥 `1` 的公钥必须等于生成点 `G`
- `BIP32`：种子 `000102030405060708090a0b0c0d0e0f` 推出的主私钥、链码、`m/0'`，与 BIP32 规范文档逐字节一致
- `BIP39`：熵全为 0 时必须得到 `abandon abandon ... about`
- `hash160`：`RIPEMD160(SHA256(b"abc")) == bb1be98c...`

跑 `python3 btclib.py` 可以看到完整的自检输出（10 项）。

几个值得单独跑的例子：

- **`ch03_ecdsa.py`** — 完整复现 2010 年索尼 PS3 被破解的过程：复用随机数 `k` 后，攻击者只用两条签名就把私钥完整算了出来。
- **`ch19_minibtc.py`** — 150 行实现一个能挖矿、能转账、能检测篡改的区块链。改掉历史上一个块的金额，整条链立刻失效。
- **`ch15_bip32.py`** — 直观看到"一个种子 → 无限地址"，以及硬化派生为什么能防止 xpub 泄露导致全盘失守。

## 在线版本

这个仓库同时是 GitHub Pages 站点（`i3wangyi.github.io`）。根目录的 `index.html` 是书的部署副本，
内容与 `bitcoin-from-scratch.html` 一致，只是额外带了 description / canonical / Open Graph 几个 meta 标签。

**改书之后要同步两个文件**：改 `bitcoin-from-scratch.html`，然后把新内容复制成 `index.html` 并保留那几行 meta。
（避免只改其中一个，导致线上版本和仓库里的书对不上。）

## 免责声明

书中和代码里出现的所有私钥、地址、交易均为**教学构造的示例**。

**绝对不要**把示例私钥用于存放真实资产。这些代码未经安全审计，也不适合直接用于生产环境——
